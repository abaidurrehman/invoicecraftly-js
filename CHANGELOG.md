# Changelog

## 0.1.0 — 2026-09-08

- Publish the first TypeScript client for the released InvoiceCraftly API v1 surface.
- Support PDF generation, EN16931-core readiness diagnostics and the currently supported structured XML artifact.
- Preserve public API error status/code/request ID and expose retry timing when provided.
- Add timeout and AbortSignal support.
- Keep the package dependency-free at runtime.
- Add reproducible CI, npm release guidance and a Trusted Publishing workflow for future releases.
